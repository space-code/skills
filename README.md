## Description
Dev Productivity Kit is a curated ecosystem of production-ready **Skills** and plugins tailored specifically for **Claude Code**. It enables mobile, backend, and platform engineers to automate daily boilerplate processes, enforce team formatting standards, and optimize cognitive load directly inside the terminal interface.

## Available Plugins & Skills

| Plugin Name  | Skill Command | Description |
|-----------|----------------|----------------|
| git-suite       | `/conventional-commits`          | Generates semantic commits adhering to Conventional Commits 1.0.0. Max 50 chars for headers, 72 chars hard wrap for bodies, auto-detects BREAKING CHANGE. |
